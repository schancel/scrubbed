Best practices for organizing a home workshop?

I've been slowly filling my garage with tools over the last few years and it's turned into a disaster. Does anyone have a system that actually works for keeping hand tools and power tools organized long term?

Pegboard changed everything for me. I traced an outline around each tool so it's obvious immediately when something is missing or was put back in the wrong spot after a project finished last spring.

Second the pegboard suggestion, and I'd add labeled bins for small hardware like screws and anchors, sorted by size rather than by project, since projects change but sizes generally don't.
